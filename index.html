Dimension Measurement Form

Read handwritten measurements from a photo, check them, then export to Excel or PDF. Units in mm.

Reader settings (needed to read photos)

Photos are sent to the API address below using your own API key. Use only a key and address approved by your company. The key is kept in this browser tab only and is cleared when you close it. Never put a key in this file or commit it to GitHub.

Snap & read

Take a clear, straight-on photo of the handwritten paper, then tap Read. Package columns, spec limits, header and measurements are read from the paper.

Red = outside Min/Max. Yellow = unsure digit. Tap any cell to fix it. Avg, Max and Min are automatic.
